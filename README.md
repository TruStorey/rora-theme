# Rora

> *A cosy, calm dark theme — vivid aurora accents against a deep arctic night.*

Rora is one palette — 25 colours — ported across the terminal, the editor, and
the dashboard, so the tools you keep open all night look like the same place.
Deep arctic backgrounds, a cool aurora spectrum for syntax, and a single warm
note of moonlight used sparingly.

The terminal ports share one ANSI palette — Windows Terminal, Ghostty, GNOME
Terminal, and the VS Code integrated terminal match slot-for-slot, so Rora
reads identically wherever a shell is open.

## The palette

Five background stops from deepest void to visible horizon, five foreground
steps from starlight down to barely-there, ten cool aurora accents, and one
warm lunar note.

| | | |
|---|---|---|
| Abyss `#12101c` | Starlight `#eddeff` | Violet `#b59eff` |
| Dusk `#1a1728` | Veil `#a89cc8` | Aurora `#72f0c8` |
| Horizon `#2e2a45` | Mist `#7a7096` | Polar `#7ec8f4` |

**[Full palette reference →](docs/rora-palette.md)** — all 25 colours with
names, hex values, roles, and the naming system behind them.
